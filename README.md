# 🧬 DNA Sequence Analyzer

A beginner-friendly **bioinformatics web application** that analyzes DNA sequences using Python, Flask, HTML, CSS, and JavaScript.

The project demonstrates how **biotechnology + programming + bioinformatics** can be combined to analyze biological sequence data.

---

## 📌 Project Overview

DNA Sequence Analyzer allows users to enter a DNA sequence and perform basic sequence analysis.

The application can:

- 🧬 Validate DNA sequences
- 📏 Calculate sequence length
- 🧪 Calculate GC content
- 🔬 Calculate AT content
- 🔢 Count individual nucleotides
- 🔄 Generate reverse complement
- 🧫 Transcribe DNA into RNA
- 📊 Calculate nucleotide percentages
- 📋 Copy generated sequences
